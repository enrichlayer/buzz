# el-buzz logo concept

`logo-concept.png` was generated with the built-in image generation tool from
`desktop/src-tauri/icons/icon.png` as the upstream shape reference. This is a
brand lockup concept, not the native app icon asset.

Prompt: Preserve Buzz's two circular wings, rounded rectangular body, two eye
cutouts and two horizontal slots. Reinterpret the bee as a precise technical
illustration with sage outlines, dotted construction guides and small pink
registration crosses on charcoal. Place the exact lowercase wordmark `el-buzz`
to its right in a clean white sans serif. Keep the composition flat, restrained,
recognizable and spacious, with no extra text or mockup.

The app theme uses the live design-token source values. The illustration's
colors are visual guidance; generated raster pixels are not a token source.

`app-icon.png` is the square native icon derived from the approved lockup by
image generation: the bee alone, sage technical outlines and dotted guides,
pink registration marks, charcoal background, without a wordmark.
The Tauri icon command generated the committed PNG, ICNS and ICO sizes in
`desktop/src-tauri/icons/el-buzz` from that source.
